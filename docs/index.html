Para que serve

Monitorar a CPU sem abrir o System Monitor. O CPU Core Temps exibe na barra de tarefas a temperatura de cada núcleo físico (não das threads HT/SMT), com cores distintas e alerta visual quando a temperatura sobe.

Ideal para quem compila, joga ou simplesmente quer um olhar rápido no aquecimento real do processador — sem gráficos, sem popup obrigatório, só o texto que importa.

🔬

Só núcleos físicos

Usa a topologia do kernel para agrupar threads e mostrar um valor por núcleo real.

🎨

Cores por núcleo

Cada núcleo tem uma cor própria; passa a laranja/vermelho nos limites de aviso e crítico.

⚡

Leve e nativo

QML + ksystemstats (mesma base do System Monitor). Sem dependências extras pesadas.

⚙️

Configurável

Limites de temperatura, intervalo, rótulos, separador e tamanho da fonte.

Como usar

  1. Instalar o plasmoid

    Baixe o arquivo mais recente em GitHub Releases e na pasta onde extraiu o arquivo, execute os comandos abaixo:

        unzip cpu-core-temps-v1.0.0.zip
    cd cpu-core-temps-v1.0.0
    chmod +x install.sh
    ./install.sh

    Instalação manual (opcional)

        # Cria os diretórios necessários de forma segura
    mkdir -p ~/.local/share/plasma/plasmoids
    mkdir -p ~/.local/share/icons/hicolor/scalable/apps

    # Remove versão anterior se existir para evitar pastas aninhadas
    rm -rf ~/.local/share/plasma/plasmoids/com.github.murilomunhao.cpu-core-temps

    # Copia os arquivos do plasmoid e o ícone do sistema
    cp -r package \
      ~/.local/share/plasma/plasmoids/com.github.murilomunhao.cpu-core-temps
    cp package/contents/icons/com.github.murilomunhao.cpu-core-temps.svg \
      ~/.local/share/icons/hicolor/scalable/apps/

    # Reinicia o Plasma Shell para aplicar as alterações
    systemctl restart --user plasma-plasmashell.service

  2. Adicionar ao painel

    Botão direito na barra de tarefas → Editar painel → Adicionar widgets → procure por CPU Core Temps e arraste para o painel.

  3. Confirmar sensores

    O sistema precisa expor temperaturas via ksystemstats. Se nada aparecer, configure o lm_sensors ((sudo sensors-detect) e verifique com o comando sensors.

  4. Ajustar preferências

    Botão direito no widget → Configurar CPU Core Temps… para mudar limites, intervalo e aparência.

Configuração

Opção Padrão Descrição
Temperatura de aviso 75 °C Inicia transição para tons de laranja/vermelho
Temperatura crítica 90 °C Vermelho intenso e negrito
Intervalo 2 s Frequência de atualização dos sensores
Rótulo do núcleo Sim Mostra C0:, C1:, …
Unidade Sim Exibe o símbolo °
Separador espaço Texto entre um núcleo e o próximo
Tamanho da fonte auto 0 = fonte do tema; ou valor em px

Requisitos

Plasma 6

Feito para Plasma 6 / Qt 6. Não testado em Plasma 5.

ksystemstats

Já incluso numa instalação típica do KDE Plasma.

lm_sensors

Necessário para o kernel expor as temperaturas da CPU.

Em alguns processadores AMD o kernel só fornece temperatura de pacote (não por núcleo). Nesse caso o widget mostra a média disponível.
